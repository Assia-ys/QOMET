# Installation QOMET

## Windows

1. Télécharger et décompresser l'archive QOMET
2. Double-cliquer sur **`install.bat`**
3. Un raccourci **QOMET** apparaît sur le Bureau
4. Double-cliquer sur le raccourci pour jouer

## Linux

```bash
chmod +x install.sh
./install.sh
```

## macOS

```bash
chmod +x install.sh
./install.sh
```

---

## Prérequis

Aucun — Python et Node.js sont inclus dans l'application.

## Support

Windows 10+, Ubuntu 20.04+, macOS 12+
